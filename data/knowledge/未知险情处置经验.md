# 未知险情处置经验(研判参考)

> 用途: 仿真评估 Agent 每轮自主研判的参考经验。这些是「征象 → 判断 → 处置 → 禁忌」,
> 靠相似度匹配, 允许组合与超出——它们不是代码分支, 不穷举所有情况。
> 通用尺度: 优先级为 人员安全 > 通信连续 > 火势不扩大 > 资源节约; 拿不准往高一级处理, 宁可过防。

## 风况突变

- 征象: 观测风速偏离预期带、连续同向漂移、档位边界附近反复、风向旋转。
- 判断: 风变同时改变 K_wind 与药剂效率, 存量 FLP 需重标定; 下风向网格与出口先受害。
- 处置: 轻微漂移 → 盯防; 影响药剂效率或火向下风向人员/出口蔓延 → 重规划, 优先把压制力量调往下风向。
- 禁忌: 单轮读数就改方案(那是噪声); 只看风速升档、忽略风向旋转(对疏散同样致命)。

## 火势超预期

- 征象: 实际 FLP 连续高于轮次预估、增长曲线变陡、出现新着火格。
- 判断: 先区分"增长模型低估"还是"环境变了"(风/燃料/坡度); 再看净处置能力 C_net 余量。
- 处置: 余量仍在 → 盯防并收紧; 余量趋零 → 重规划增援; C_net 转负 → 输出资源缺口, 不给虚假完成时间。
- 禁忌: 用旧增长率外推新态势; 为了"看起来能完成"压低读数。

## 单机异常

- 征象: SOC 降幅明显快于同型同任务机、位置长时间不更新、该到的架次没到、长期滞留周转状态。
- 判断: 与同型机横向对比区分"正常周转"与"真异常"; 真异常即压制能力受损, 重算 C_net。
- 处置: 队内还有可用机 → 立即补位, 不等火涨; 无机可补 → 降级目标(控火→遏制)并上报缺口。
- 禁忌: 等多轮卡滞才动手; 把异常机继续算进可用能力。

## 执行中新发现人员

- 征象: 监测/复核报告出现人员, 原判 absent/unknown 被推翻。
- 判断: 人员安全升为最高优先级, 灭火调度让位; 核心量是"人群到达安全区 vs 火到达人群"的相对速度。
- 处置: 立即切有人分支、重算疏散路线; 若火会先到, 评估调灭火机在通道上打隔离带开路。
- 禁忌: 按"无人"分支继续跑完; 只广播不评估路线可达性。

## 多点火情

- 征象: 巡逻或监测报出与主火场不连通的新火点。
- 判断: 资源不再平均分——按各点增长速度与威胁(人员/出口/设备)排序分主次。
- 处置: 主点保 C_net>0, 次点至少维持监视; 总量不够 → 上报最小增援清单。
- 禁忌: 机队平分导致两处都 C_net≤0; 只盯主点对次点装看不见。

## 通信退化

- 征象: 信号低于阈值、遥测断续、指令回执延迟、多机同时远距。
- 判断: 失联机不可控, 等于能力已经损失; 中继与活动半径是资源。
- 处置: 派中继悬停 / 收缩活动半径 / 召回远端机; 对失联机按"最后已知状态"做保守假设。
- 禁忌: 把失联机当可用; 链路恶化时还加派多机远距任务。

## 库存见底

- 征象: 水剂 / CO₂ 模块 / 电池组低于"剩余任务预计消耗"。
- 判断: 还能撑几轮? 补给链路(运送/换电/充电)哪条最慢? 基地保留量是多少?
- 处置: 提前补, 不等断供; 断供不可避免 → 输出缺口与最短增援清单, 目标降级。
- 禁忌: 给出虚假完成时间; 掏空基地保留量去赌。

## 疏散路线被封锁 / 人群被困

- 征象: 火格与路径格重合、人群进度停滞、出口不可达。
- 判断: 改道必须从人群当前位置出发(不回起点); 全部出口被封 → 转就近避险。
- 处置: 重算路线并广播; 评估"打隔离带为人群开路"的选项; 人群贴火要按恐慌步速计时间。
- 禁忌: 人群位置"传送"回起点; 只报警不处置。

## 传感器矛盾

- 征象: 视觉报有火而热红外没有、两个来源风速不一致、置信度骤降。
- 判断: 矛盾本身就是需要盯防的信号; 按更悲观的来源行动, 同时派复核。
- 处置: 复核优先于大动作; 复合证据齐了再升级处置。
- 禁忌: 静默择一、忽略另一个。

## 遇到没见过的情况(通用兜底)

1. 承认未知: 明说"这是未预设情况", 不硬套最像的模板;
2. 降级运行: 沿目标链收缩——控火 → 遏制 → 监视 → 保存机队, 保住优先级最高的事;
3. 保守默认动作: 召回有人附近的机、全员转监视、冻结新架次——默认动作永远是"更安全"的那个;
4. 上报人工: 给出"准备做什么 + 理由 + 风险", 请求人工确认; 超时按保守默认执行, 不悬停等待;
5. 沉淀复盘: 任务结束后把这次判断写回本经验库, 下次它就不再是未知。

## 判断纪律

- 只引用快照与工具读数里的数字, 严禁编造或心算外推;
- 每次研判必须给出多个选项并写明取舍理由, 不允许"无选项默认继续";
- 静默吞掉异常观测是最大禁忌;
- 昨天的结论不豁免今天: 每轮都重新研判。
